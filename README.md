# Prototypes

Экспериментальные модели, исследования и прототипы для NLP-фреймворка AutoIntent.

## Структура и компоненты
- **GCN (Graph Convolutional Networks)** — эксперименты по классификации интентов с использованием графовых сверточных сетей и эмбеддингов моделей (например, Stella).
- **HMCN (Hierarchical Multi-Label Classification Networks)** — иерархическая классификация интентов.
- **LinearTest** — базовые линейные классификаторы (Logistic Regression) для оценки качества на различных датасетах (CLINC150, Banking77, events).
